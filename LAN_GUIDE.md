# LAN Multiplayer Guide для RavenM

## Описание

Добавлена поддержка локальной сети (LAN) для игры по прямому IP-адресу без необходимости в интернете и Steam. Система состоит из трех основных компонентов:

### Компоненты

1. **LanTransport** - низкоуровневый UDP транспорт
2. **LanLobbySystem** - управление лобби через LAN
3. **LanLobbyUI** - пользовательский интерфейс для LAN

## Использование

### Создание LAN лобби (Хост)

1. В главном меню нажми кнопку **"LAN Mode"** в правом верхнем углу
2. Введи имя игрока в поле "Player Name"
3. Установи максимальное количество игроков (2-32)
4. Нажми **"CREATE LAN LOBBY"**

После создания лобби:
- Твой локальный IP-адрес и порт будут отображены в чате
- Поделись этой информацией с друзьями

### Присоединение к LAN лобби (Клиент)

1. Попроси у хоста его IP-адрес и порт (по умолчанию 7777)
2. Нажми **"LAN Mode"** в главном меню
3. Введи имя игрока
4. В разделе "JOIN LOBBY" введи:
   - **Host IP**: IP-адрес хоста (например, 192.168.1.100)
   - **Port**: порт (обычно 7777)
5. Нажми **"JOIN BY IP"**

### Автоматический поиск лобби

1. Нажми **"LAN Mode"**
2. Нажми **"SCAN NETWORK"** - система будет искать серверы в сети
3. Выбери лобби из списка найденных

## Системные требования

- **Unity Network**: System.Net.Sockets (UDP)
- **Порты**: 7777 (игра), 7778 (discovery)
- **Брандмауэр**: Убедись, что порты 7777-7778 открыты для UDP

## Технические детали

### Обнаружение (Discovery)

- Хост отвечает на broadcast запросы на порт 7778
- Клиент может сканировать сеть каждые 3 секунды
- Информация о лобби передается в JSON формате

### Синхронизация состояния

- Хост отправляет состояние лобби каждые 2 секунды
- Клиенты отправляют heartbeat для проверки соединения
- Пакеты сжимаются (DeflateStream) как в Steam версии

### Пакеты JSON

```json
{
  "type": "JOIN_REQUEST",
  "playerName": "Player1",
  "playerGUID": "12345678-1234-1234-1234-123456789012",
  "timestamp": "637123456789"
}

{
  "type": "LOBBY_STATE",
  "lobbyID": "ABC12345",
  "hostName": "HostPlayer",
  "playerCount": 2,
  "maxPlayers": 8,
  "gameMode": "Skirmish",
  "mapName": "Forest"
}
```

## Ограничения

- Максимум 32 игроков (сетевое ограничение)
- Работает только в локальной сети (или через VPN)
- Нет поддержки NAT Traversal
- Требуется открытые UDP порты на файрволе

## Решение проблем

### Не видны лобби при поиске

1. Проверь, что оба компьютера в одной сети
2. Убедись, что файрволл не блокирует порты 7777-7778
3. Попробуй подключиться напрямую по IP

### Разрыв соединения

- Хост автоматически отключает неактивных клиентов (нет heartbeat 5+ сек)
- Клиент переподключается при потере соединения

### Пакеты не доставляются

- Проверь сетевую задержку (ping)
- Убедись, что пакеты не фрагментируются (MTU ~1500 байт)

## Расширение функциональности

### Добавление поддержки маршрутизаторов

Для игры через интернет можно добавить поддержку UPnP/NAT-PMP для автоматического пробрасывания портов.

### Улучшение Discovery

Можно добавить регистрацию на центральном сервере для поиска лобби через интернет.

## Файлы

- `LanTransport.cs` - UDP транспорт (приём/отправка пакетов)
- `LanLobbySystem.cs` - управление состоянием лобби
- `LanLobbyUI.cs` - интерфейс для взаимодействия
- `LanNetworkAdapter.cs` - адаптер для интеграции с IngameNetManager

## Примечания

- Система работает параллельно со Steam, не мешая обычной игре
- Discord integration остается без изменений
- Все LAN пакеты шифруются как обычные игровые пакеты
