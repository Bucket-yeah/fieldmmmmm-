# RavenM LAN Mode - Установка и использование

## Что было добавлено

Полная поддержка игры по локальной сети без интернета и Steam. Система позволяет:

- ✅ Создавать и присоединяться к лобби через IP адрес
- ✅ Автоматический поиск серверов в сети (LAN discovery)
- ✅ Работает параллельно со Steam (не мешает обычной игре)
- ✅ UDP транспорт с поддержкой до 32 игроков
- ✅ Синхронизация состояния лобби
- ✅ Heartbeat для детекции разрывов соединения

## Файлы

Добавлены 5 новых файлов в `RavenM/`:

1. **LanTransport.cs** (293 строк)
   - UDP сокеты для приема/отправки пакетов
   - Поддержка broadcast для discovery
   - Многопоточность для неблокирующего приема

2. **LanLobbySystem.cs** (343 строк)
   - Управление состоянием лобби
   - Создание и присоединение к лобби
   - Синхронизация игроков
   - JSON протокол для пакетов

3. **LanNetworkAdapter.cs** (80 строк)
   - Адаптер для интеграции с IngameNetManager
   - Переключение между Steam и LAN режимом
   - Единый интерфейс отправки пакетов

4. **LanLobbyUI.cs** (113 строк)
   - GUI для создания/присоединения к лобби
   - Поиск доступных серверов
   - Кнопка "LAN Mode" в меню

5. **LanExamples.cs** (224 строк)
   - Примеры использования для разработчиков
   - Интеграция с IngameNetManager

Плюс обновлены:
- **Plugin.cs** - добавлена инициализация LAN компонентов

## Установка

1. Скопируй 5 файлов в папку `RavenM/`
2. Обнови `Plugin.cs` (см. изменения выше)
3. Перестрой проект

```bash
dotnet build RavenM.sln
```

## Использование

### Для хоста (создание лобби)

```csharp
var lanLobby = LanLobbySystem.instance;
lanLobby.CreateLobby("MyPlayer", maxPlayers: 8);
```

Или через UI:
1. Нажми "LAN Mode" в меню
2. Введи имя и макс. игроков
3. Нажми "CREATE LAN LOBBY"

Твой IP адрес будет показан в чате.

### Для клиента (присоединение)

```csharp
var lanLobby = LanLobbySystem.instance;
lanLobby.JoinLobby("192.168.1.100", 7777, "ClientName");
```

Или через UI:
1. Нажми "LAN Mode"
2. Введи IP хоста и порт
3. Нажми "JOIN BY IP"

### Автоматический поиск

1. Нажми "SCAN NETWORK"
2. Выбери лобби из списка
3. Присоединишься автоматически

## Требования

### Сеть
- Оба компьютера в одной локальной сети (одного роутера)
- ИЛИ подключение через VPN
- Открытые UDP порты 7777-7778 на файрволе

### Система
- Windows/Linux/Mac
- .NET Framework 4.7.2+
- Unity 2022+

## Протокол

### Пакеты JSON

**Присоединение к лобби:**
```json
{
  "type": "JOIN_REQUEST",
  "playerName": "Player1",
  "playerGUID": "guid-uuid",
  "timestamp": "637123456789"
}
```

**Состояние лобби:**
```json
{
  "type": "LOBBY_STATE",
  "lobbyID": "ABC12345",
  "hostName": "Host",
  "playerCount": 2,
  "maxPlayers": 8,
  "gameMode": "Skirmish",
  "mapName": "Forest"
}
```

**Heartbeat:**
```json
{
  "type": "HEARTBEAT",
  "playerGUID": "guid-uuid"
}
```

## Порты

| Порт | Назначение | Тип |
|------|-----------|-----|
| 7777 | Игровые пакеты | UDP |
| 7778 | Discovery broadcast | UDP |

## Ограничения

- Максимум 32 игроков (UDP сегментация)
- Только локальная сеть (нет NAT traversal)
- Нет шифрования (если нужно, добавь AES поверх)
- Нет механики восстановления потерянных пакетов (как в Steam)

## Расширение

### Добавить поддержку интернета

Для игры через интернет можно:
1. Добавить UPnP для пробрасывания портов
2. Использовать STUN сервер для NAT traversal
3. Добавить relay сервер как альтернатива

### Улучшить discovery

```csharp
// Регистрация на центральном сервере
LanLobbySystem.instance.RegisterOnMasterServer(
    "master.example.com", 
    lobbyInfo
);

// Получение списка лобби с сервера
var lobbies = LanLobbySystem.instance.QueryMasterServer();
```

## Отладка

Логирование:
```csharp
Plugin.logger.LogInfo("Сообщение");
Plugin.logger.LogWarning("Предупреждение");
Plugin.logger.LogError("Ошибка");
```

Проверка соединения:
```csharp
var transport = LanTransport.instance;
var connections = transport.GetConnections();
foreach (var conn in connections.Values)
{
    Debug.Log($"Подключение: {conn.EndPoint}");
}
```

## Известные проблемы

- [ ] Broadcast может не работать на некоторых маршрутизаторах
- [ ] Высокая задержка при слабом Wi-Fi
- [ ] Нет гарантии доставки пакетов (UDP)

## Файлы конфигурации

Нет дополнительных конфиг файлов, все настройки в коде:
- Порт игры: `LanTransport.GamePort = 7777`
- Порт discovery: `LanTransport.DiscoveryPort = 7778`
- Интервал синхронизации: `LanLobbySystem.LOBBY_UPDATE_INTERVAL = 2f`

## Поддержка

Если есть ошибки:
1. Проверь логи в консоли
2. Убедись, что порты открыты на файрволе
3. Попробуй подключиться напрямую по IP
4. Перезагрузи оба клиента
