# LAN Mode - Быстрый старт

## 🚀 За 2 минуты

### Хост создает лобби:
1. Меню → нажми **"LAN Mode"**
2. Введи имя игрока и макс. игроков
3. Нажми **"CREATE LAN LOBBY"**
4. Скопируй свой IP из чата

### Друг присоединяется:
1. Меню → **"LAN Mode"**
2. Введи IP хоста
3. Нажми **"JOIN BY IP"**

## 📡 Технические детали

| Компонент | Описание |
|-----------|---------|
| LanTransport | UDP сокеты, приём/отправка пакетов |
| LanLobbySystem | Управление состоянием, JSON протокол |
| LanLobbyUI | GUI для создания/присоединения |
| LanNetworkAdapter | Интеграция с IngameNetManager |

## 🔧 Коды ошибок

```
"Не видны лобби?" → Проверь файрволл
"Разрыв соединения?" → Проверь задержку (ping)
"Пакеты не доставляются?" → Проверь MTU
```

## 💻 Для разработчиков

```csharp
// Создать лобби
LanLobbySystem.instance.CreateLobby("Name", 8);

// Присоединиться
LanLobbySystem.instance.JoinLobby("192.168.1.1", 7777, "Name");

// Получить игроков
var players = LanLobbySystem.instance.GetLobbyPlayers();

// Отправить пакет
LanTransport.instance.SendPacket(endpoint, data);
```

## ⚙️ Параметры

```csharp
LanTransport.GamePort = 7777;           // Порт игры
LanTransport.DiscoveryPort = 7778;      // Порт поиска
LOBBY_UPDATE_INTERVAL = 2f;              // Синхронизация каждые 2 сек
```

## 🎮 Совместимость

✅ Работает со всеми игромодами (Skirmish, Domination и т.д.)
✅ Параллельно со Steam (не мешает)
✅ Windows/Linux/macOS
❌ Не работает через интернет (только локальная сеть)

## 📊 Производительность

- **Максимум игроков**: 32
- **Задержка пакетов**: < 50ms (в локальной сети)
- **Размер пакета**: до 65KB

## 🔐 Безопасность

⚠️ Без шифрования! Для локальной сети внутри одного роутера достаточно.

Если нужно через интернет - используй VPN.

## ❓ FAQ

**В: Почему нет поиска серверов через интернет?**
А: Это требует NAT traversal и relay сервера. Для домашней сети достаточно локального поиска.

**В: Можно добавить пароль на лобби?**
А: Можно, но это требует добавления поля в LanLobbyInfo.

**В: Что будет, если хост отключится?**
А: Клиенты получат ошибку соединения и вернутся в меню.

**В: Как увеличить максимум игроков?**
А: Измени `maxPlayers` при создании лобби, но более 32 не рекомендуется из-за UDP.
